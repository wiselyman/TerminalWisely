# Home 主机目录分组层级与紧凑布局

## 要保住的旧行为

- Home 仍按已保存分组顺序展示主机，Ungrouped 和空分组仍可见。
- 分组内拖动目标仍覆盖完整分组区域；主机卡片仍可点击打开 Desktop。
- 分组/主机操作仍仅在对应区域 hover 或键盘 focus 时出现。
- 新建分组、编辑和删除行为不变，删除分组后的主机仍进入 Ungrouped。

## 架构

| 职责 | 文件 |
|---|---|
| 主机目录布局语义和稳定测试标记 | `src/components/home/HomeHostDirectory.tsx` |
| 分组标题栏层级、卡片尺寸与纵向密度 | `src/styles/home.css` |
| 布局层级、间距和拖放范围回归 | `e2e/home-host-directory.spec.ts` |
| Home 目录功能测试映射 | `docs/TEST_MATRIX.md` |

依赖方向不变：组件表达分组和主机结构，CSS 负责视觉层级与紧凑间距，E2E 通过结构和 bounding box 验证。无需新增组件或改变数据流。

## 设计

- 分组名称和主机数使用实色浅色标题带、左侧强调色及清晰边界，成为每组的视觉锚点；标题带与主机卡片区仍保持一个可拖放的分组容器。
- 缩小页面外边距、工具栏与首组间距、组间距、组内留白、标题高度和主机卡片尺寸；采用更紧凑的网格间距，减少长列表的整体高度。
- 加载时仍在目录中显示原有加载提示；空组仍在组内显示空状态；成功时显示紧凑主机卡片，不新增状态文案。
