# MarkWisely 自动保存与窗口恢复布局

## 要保住的旧行为

- 打开或新建 Markdown 文档后，编辑器仍可编辑，手动“保存”仍立即把当前内容写回当前 Local 或 SSH 目标。
- 编辑中的文档仍按 Local/SSH 目标隔离；最近文件仍归属对应目标。
- 关闭或离开尚未持久化的文档时，不丢弃编辑内容：先立即保存；保存失败时阻止离开并保留编辑内容。
- Desktop 应用窗口最大化、恢复后仍保持原有窗口状态与内容，不重建文档或丢失光标内容。

## 架构

- `src/components/desktop/MarkWiselyWindow.tsx`：负责文档自动保存的防抖调度、状态反馈、离开/关闭前冲刷保存。
- `src/stores/markWiselyStore.ts`：确保保存串行且编辑期间的新内容不会被较早的保存覆盖；继续通过既有 Local/SSH 文件接口落盘。
- `src/components/preview/MarkdownWysiwygEditor.tsx`：观察编辑器容器尺寸变化并同步 Vditor 内部编辑区域宽度，不重建编辑器实例。
- `src/components/desktop/MarkWiselyWindow.css` 与 `src/styles/files.css`：保证 flex 子项可收缩且 Vditor 主体始终填满可用宽度。
- `e2e/host-desktop.spec.ts`：覆盖远程文档自动保存，以及 MarkWisely 最大化后恢复时编辑区宽度恢复；相关工作台现有交互保持不变。

## 设计

- 用户在 MarkWisely 编辑器输入后，停止输入约 700ms 自动保存；保存过程中状态显示“正在保存…”，成功显示“已保存”，失败在编辑器上方显示错误并保留未保存文本。手动保存按钮继续作为立即保存入口。
- 用户在自动保存等待期间离开或关闭编辑器时，先立即冲刷保存；保存成功后继续原操作，保存失败则留在编辑器并显示错误。
- 最大化后恢复窗口时，编辑区随当前窗口宽度重排；加载、保存和失败状态仍显示在 MarkWisely 编辑区内，不弹出额外对话框。
