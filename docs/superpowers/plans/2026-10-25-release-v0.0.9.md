# TerminalWisely v0.0.9 Release Plan

**Goal:** Publish the verified current `main` as TerminalWisely v0.0.9 and let GitHub Actions build and attach the platform installers.

## 要保住的旧行为

- All Home, Hosts, Kubernetes, Databases, Terminal, Desktop, file-manager, and MarkWisely behavior covered by `./scripts/run-all-tests.sh` continues to pass.
- Release builds remain triggered by pushing `v0.0.9`, and GitHub Actions publishes the release assets using the existing workflow.
- Version displayed in the application, package metadata, README, changelog, and release notes is v0.0.9.

## 架构

- Release version metadata lives in `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`, and `src-tauri/tauri.conf.json`.
- User-facing release description lives in `RELEASE_NOTES.md`, `CHANGELOG.md`, `release-notes/v0.0.9.md`, `README.md`, and `README.zh-CN.md`.
- `.github/workflows/release.yml` builds the binaries on tag push; no local platform packaging changes are needed.

## 设计

- GitHub Release presents concise bilingual highlights for the changes since v0.0.8 and links the platform assets produced by CI.
- Failure: if local full tests fail, stop before commit/tag; if GitHub Actions fails, report the failed job and leave the release clearly identified as incomplete.
- Success: publish the release directly (existing workflow is non-draft) after tag push and confirm the release assets are present.
