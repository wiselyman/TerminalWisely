# MarkWisely 文件操作工具栏设计

## 目标

在 MarkWisely 编辑 Markdown 时，将 Open、Open Folder、Save、Save As、Export 放入现有 Vditor 格式工具栏的左右空白区域，避免新增第二条操作栏。文件名继续显示在 MarkWisely 应用标题栏中央；自动保存和编辑区右下角的保存状态继续工作。

## 交互

- **Open**：打开现有 Markdown 文件选择框，选中文档前先保存当前脏内容。
- **Open Folder**：打开文件夹选择框，确认目录后继续显示该目录下的 Markdown 文件选择框；选中文档前先保存当前脏内容。
- **Save**：立即保存当前文档；已保存时保持无操作且不报错。自动保存仍按既有时机运行。
- **Save As**：打开目标目录选择框，再使用当前文件名作为建议文件名；确认后将当前编辑器中的完整内容写入同一 Desktop target 下的新文件，并切换到新文件。源文件不被另存为覆盖。失败时留在原文档且保留编辑内容。
- **Export**：通过系统保存对话框将当前编辑器内容导出到本机选定的 Markdown 路径；不改变当前文档路径或 Desktop target。
- 所有按钮使用 Vditor 自定义菜单项及本地化 tooltip/可访问名称。文件操作项放在工具栏两端，格式工具保持中间顺序；窄窗口允许工具栏横向滚动，不遮住编辑区。

## 状态与错误

- 加载/保存状态仍显示在编辑窗口右下角。
- 打开期间的保存失败保留在当前文档并显示已有错误区域；另存为失败留在源文档并显示创建/写入错误。
- 导出取消不提示错误；导出成功/失败使用现有应用 toast/错误反馈，不改变文档的自动保存状态。
- Local 与 SSH 文件操作继续沿用现有 target 路由，Save As 新文档与当前 target 相同。

## 验收

- 编辑器工具栏存在 Open、Open Folder、Save、Save As、Export 五个操作，左右留白由它们占用，不出现重复工具栏。
- 两种打开入口可导航并打开 Markdown；另存为复制当前缓冲内容并切换到新路径；Export 只生成本机副本。
- 自动保存、标题栏文件名、Home/SSH target 隔离和文件预览原有 Vditor 工具栏保持不变。
- Playwright 覆盖按钮布局/可发现性、打开文件、打开文件夹、保存、另存为、导出成功与取消，以及窄窗口下工具栏无重叠。
