# 当前交接（2026-11-18）

当前产品聚焦本机与 SSH Hosts 两类工作区：Home 主机目录置顶显示 Local，并按既有分组列出已保存 SSH Hosts；点击 Local 或 SSH 主机会在新标签打开对应 Desktop。Home 目录不再显示 Terminal 与聊天入口按钮，本机 Terminal 与聊天仍可从对应工作区标签和工具使用；SSH Hosts 提供远程 Terminal 与 Desktop。MarkWisely 和 EditorWisely 作为 Desktop 内置工具保留。

Home 使用本机聊天 scope；SSH Hosts 使用当前已连接会话，不另建 SSH 连接。文件管理器与 EditorWisely/MarkWisely 应沿用对应工作区的文件读写和会话上下文。
