# TerminalWisely v0.0.1

跨平台 **SSH 终端**，集成 SFTP 文件工作区与 **AI Linux Engineer**。

## 亮点

- 多标签 SSH、书签、拖拽上传、`ls` 点击进入、预览编辑、下载、跨服发送
- AI 工程师在当前会话排障（OpenAI 兼容、Ollama、Anthropic 兼容、Gemini）
- 命令能力分级与批准 UI；随时停止 AI
- 状态栏主机指标；中英文界面
- 安装包：Windows；macOS（arm64 / x64）；Linux（deb / rpm / AppImage，arm64 / x86_64）

## 安装

在 **Assets** 中选择对应系统安装包。首次使用 AI 工程师时会自动安装依赖。
