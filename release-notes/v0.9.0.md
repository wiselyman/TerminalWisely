# v0.9.0

## Added
- 界面中英文切换（地球图标）；中文系统默认中文，其他默认英文，可手动切换并记住
- 终端右键：文件/文件夹「压缩」为 `.tar.gz`；压缩包「解压」（tar/zip/gz 等）
- 终端空白处右键：SSH「上传」、粘贴剪贴板文本

## Fixed
- 含空格或超长路径下 `ls` 列表不可点击（提示符折行后识别失败）
- 命令导航英文检索只匹配中文标题、英文标题为 id 缩写的问题
- SSH 连接表单名称/用户名自动首字母大写
- 预览编辑卡顿与语法高亮闪烁；不可写文件（如 `/etc/docker/daemon.json`）sudo 保存
- 终端粗体选区错位；macOS 交通灯位置

## Changed
- 命令导航英文标题改为可读文案；检索同时匹配本地化标题、分类与命令 id
