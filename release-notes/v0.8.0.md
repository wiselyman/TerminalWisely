# v0.8.0 — SSH 右键下载/跨服发送与工作区界面

## 新增

- **SSH 文件右键菜单**：在 `ls` 列表右键文件或文件夹，可下载到本机、发送到其他 SSH 服务器、编辑和预览、查看大小；文件夹下载为 `.tar.gz`（Windows / macOS / Linux 一致）
- **跨服发送对话框**：先选择目标 SSH 会话，再用路径输入框指定远程目录（支持 Tab 补全），确认后启动传输
- **路径大小**：右键「查看大小」显示远程文件或目录占用

## 改进

- **工作区界面**：自定义标题栏与窗口拖拽；侧栏与右侧工具轨 Lucide 图标；面板背景遮罩
- **预览**：预览停靠区与 sudo 密码弹窗统一
- **页签**：拖拽排序幽灵标签与标签栏内探测

## 修复

- 切换工作区面板时终端列宽与焦点行为若干问题
