# TerminalWisely v0.0.2

## English

### In-app updates (GitHub Releases)

- Quiet check shortly after launch; a bright download badge appears in the sidebar when an update is available (hidden otherwise)
- Confirm before download/install; progress and restart prompt
- Manual **Check for Updates…** in the app menu (macOS) / Help (Windows & Linux); Settings gear as fallback
- Signed updater artifacts + enriched `latest.json` (including Linux deb/rpm custom targets)

### Also in this release

- About dialog uses the TerminalWisely app icon
- Clear dialog feedback when already up to date or when the check fails

## 中文

### 应用内在线升级（GitHub Releases）

- 启动后静默检查；有新版本时在侧栏底部显示亮色下载图标（无更新则不显示）
- 确认后再下载安装；显示进度，装完提示重启
- 手动检查：macOS 菜单栏 **Check for Updates…**；Windows / Linux 在 **Help**；设置里也可检查
- 发布产物带 updater 签名，并生成含 Linux deb/rpm 自定义 target 的 `latest.json`

### 其他

- 「关于」对话框显示 TerminalWisely 应用图标
- 已是最新或检查失败时弹出明确提示
