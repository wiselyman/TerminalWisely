**用自然语言修 Linux。** 跨平台桌面终端 + **AI Linux Engineer**（SSH 主机）。

## 更新内容（v1.0.0）

### 重磅：AI Linux Engineer
- 在已连接的 **SSH** 主机上，用自然语言描述问题（磁盘满、端口占用、服务 502、Docker 占空间等）
- 侧车 Agent 在真实会话中执行与验证；按主机隔离对话，支持多会话历史
- 支持 OpenAI 兼容 API（含本地 vLLM / Ollama）
- 运行中可停止或插话；变更命令 UI 精确批准

### 安全（Harness 说了算）
- **能力策略引擎**：按 argv/能力标签定级 R0–R4（YAML：`agent-sidecar/policy/`，可用户覆盖）
- 只读自动执行；变更需批准；灾难级拒绝；未知命令偏严
- 防火墙/SSH 等网络危险变更：备份 + 定时回滚，降低锁死风险
- API Key 本机存储；无绕过策略的静默提权通道

### AI 引擎自理（开箱即用）
- 发行包内嵌独立 Python（python-build-standalone 3.12.13）；**首次打开 AI 面板**时自动创建私有环境并安装依赖，**用户无需手动 pip**
- 启动过程在 AI 面板显示进度（准备环境 / 安装依赖 / 启动）；**不阻塞应用主界面**
- 首次打开 AI 可能需 1–3 分钟，请保持网络畅通；之后秒开

### 界面（Cursor 风格）
- 工具入口收入标题栏（AI / 查找 / 任务管理 / 命令导航）；侧栏可完全收起
- AI 等右侧面板：新建 / 历史 / 钉住 / 收起；主机资源指标移至底栏状态条
- 标题栏高度与交通灯垂直对齐更紧凑

### 产品范围
- **仅 SSH 远程会话**（已移除本机本地终端入口）
- 拖拽上传、点击浏览/预览、右键下载与跨服、Find、任务管理、命令导航等能力保留

### 修复
- 应用启动不再预热 AI 引擎，避免首次安装后白屏 / 鼠标长时间转圈
- 纠正「空转计划」误杀：正常 `ps` / `lscpu` 等诊断命令执行后可正常汇总，不再误停本轮
- 侧栏完全收起后工作区不再黑屏
