# v0.5.4 — 书签、Find 预览与本地任务管理器

## 连接与预览

### 书签自动保存
- 未填写连接名称时，成功连接后自动以 **IP/主机地址** 保存书签
- 相同 host + 端口 + 用户名会 **更新** 已有书签，避免重复条目

### Find 打开文件
- 在 Find 结果中点击文件打开预览时，自动关闭 Find（及任务管理器、服务器资源等同级抽屉）
- 修复预览/编辑面板被 Find 浮层遮挡、无法操作的问题

## 任务管理器

### 本地会话（macOS / Linux / Windows）
- 与 SSH 一致的分阶段加载：先显示进程 CPU/内存，再后台解析端口
- 首次打开骨架屏；列头端口 spinner；刷新时表格轻微变暗提示同步中
- CPU/内存 2 秒、端口 8 秒分开轮询

### 稳定性
- 修复端口轮询因 loading 状态长期占用而被跳过的问题

## 说明

本版本亦包含 v0.5.3 中已合入但未单独发版的任务管理器改进（SSH 分阶段加载、隐藏内核线程、结束进程不再闪回、断开友好提示等）。详见 [`v0.5.3.md`](./v0.5.3.md)。
