# v0.5.6 — 本地 OS 图标、路径修复与表单样式

## 本地终端

### 页签与书签
- 本地页签与书签首项显示 **OS 图标**：Windows 四格窗标、macOS Apple、Linux Tux
- 书签标题：**Windows / macOS / Linux 本地终端**
- **「+」** 仅打开 Remote SSH 连接（本地已在书签置顶）

### 路径与点击
- **Windows**：回到 `~` 使用用户目录绝对路径；兼容 cmd `&&` 与 PowerShell
- **macOS**：连续点击同级 `ls` 目录不再误报「路径不存在」；`enter_directory` 使用解析后的绝对路径

## 界面

- 修正 Windows 图标在小尺寸下变形
- macOS 下 SSH 连接表单「认证方式」下拉框高度与输入框一致
