# v0.7.0 — 文件右键管理、跨服 SCP 直传与 SSH 连接加速

## 新增

- **终端文件右键菜单**：在 `ls` 列表中的文件/文件夹上右键，支持重命名、删除、移动到目录
- **复制文件名称 / 复制文件路径**：右键菜单快捷复制
- **跨服务器 SCP 源机直传**：拖拽或发送到其他 SSH 会话时，在源服务器执行 `scp` 直传目标机（书签密码自动注入）
- **目录打包下载**：Ctrl/Cmd+点击文件夹可打包为 `.tar.gz` 下载

## 改进

- **SSH 首次连接加速**：认证后立即打开 Shell；OS 探测与 `$HOME` 解析改到后台，不再阻塞首屏
- **连接可靠性**：TCP 20 秒超时、失败自动重试、30 秒 keepalive；重连时先关闭旧 Shell 再建新连接
- **传输进度**：显示目标路径；SCP 直传完成自动关闭进度条
- **Find**：打开时自动同步当前工作目录；路径输入支持 Tab 补全
- **终端链接**：`ls` 悬停下划线更稳定；目录名 `ls -F` 尾缀 `/` 用于右键判断类型

## 修复

- 文件右键探测路径失败时不再弹出 `No such file` 红色 toast
- 文件操作对话框取消/确认按钮等宽
- 后台更新 `$HOME` 时不再覆盖用户已 `cd` 的当前目录
