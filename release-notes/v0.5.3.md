# v0.5.3 — 任务管理器体验优化

## 改进

### 加载更快、更少等待
- SSH 任务管理器分阶段加载：先显示 CPU 最高的用户进程，再后台解析端口
- 首次打开显示骨架屏；再次打开同一会话时先展示缓存列表并静默刷新
- 进程列表按 CPU 排序；轮询时 CPU/内存 2 秒、端口 8 秒分开刷新

### 进程列表更准确
- 默认隐藏内核线程（`[kthreadd]`、`kworker` 等），与 Ubuntu 系统监视器一致
- 进程名使用 `comm` 字段；修复 bash 将 `[...]` 误解析为通配符导致的乱名
- 修复结束进程后列表闪回的问题（已结束 PID 在确认消失前不再显示）

### 交互与稳定性
- 结束进程后立即从列表移除
- SSH 断开时停止刷新，提示「连接已断开」而非 `Channel send error`
- 端口解析进度仅在「端口」列标题旁显示转圈，避免页面跳动
