# v0.6.0 — 命令导航

## 新增

- **命令导航**：贴边工具栏打开，内置 90+ 条 Linux 运维命令，按服务、日志、磁盘、进程、网络、软件包、文件等分类浏览
- 点击命令后填写参数，**一键插入当前终端**（不自动执行，由你确认后回车）
- 支持**自定义命令**；按连接机器的发行版（Debian / RHEL / Alpine / SUSE / Arch）自动筛选相关命令
- **网络与防火墙**：监听端口、连接统计、端口占用、UFW / firewalld 状态与开放端口、iptables / nftables 查看等
- **多发行版软件包**：apt、dnf/yum、apk、zypper、pacman 搜索与常用操作

## 改进

- **场景化参数向导**（无需记忆专业术语）：
  - 服务名：systemd 单元下拉搜索
  - 路径：Tab 补全
  - 进程：按名称或 PID 选择
  - 权限：chmod 场景卡片 + 读/写/执行勾选
  - 属主：用户 / 用户组列表选择
  - 搜索：文件内容、软件包、文件名等预设场景
  - 端口：22 / 80 / 443 / 3306 / 8080 等常见端口点选
- 命令面板以浮层覆盖显示，不挤压终端布局

## 后端

- 新增 `list_systemd_units`、`list_passwd_accounts`、`complete_path` 等 Tauri 命令，供参数向导拉取远程数据
