# v0.5.5 — 本地终端、跨服传文件与 Find 预览

## 本地终端

### 路径与当前目录
- 本地会话跟踪 **cwd**（`cd`、相对路径、`~`）
- 点击 `ls` 输出中的路径可 **进入目录** 或 **打开预览**
- **Find** 在本地标签从当前目录搜索，不再固定从 `~` 开始

### macOS 体验
- 启动本地 Shell 时设置 `TERM=xterm-256color`、`CLICOLOR=1`、`LSCOLORS` 等，**彩色 ls**
- `ls -l` 解析支持 macOS 扩展属性标记（如 `drwxr-xr-x@`）
- 可点击路径 **下划线** 与悬停样式

## 跨会话传文件

- **本地 → SSH**：Shift+点击文件路径，或 Ctrl/Cmd+拖拽到 SSH 标签，经「发送到其他服务器」上传至目标会话当前目录
- 本地上传/下载（SFTP 拖拽、修饰键下载）仍 **仅 SSH 会话** 可用

## Find 与预览

- 打开/关闭预览时 **Find 不再自动关闭**
- 预览打开时 Find 面板左移，与预览并排，避免遮挡
