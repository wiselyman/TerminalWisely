# TerminalWisely v0.1.4

## English

TerminalWisely 0.1.4 makes EditorWisely a file workspace and fixes direct opening of local Markdown documents in MarkWisely.

### Highlights

- **EditorWisely file tree** — browse local and SSH-host directories from the editor and open files without leaving the workspace
- **Multiple editor tabs** — keep several documents open and switch between them while retaining each document's editing state
- **Open text files** — double-click text files in Local Desktop Files or SSH Files, or send an operating-system file-open request, to open them in a normal EditorWisely window; toggle the file tree from the title bar, where it expands to the active file's directory
- **Open Markdown documents** — operating-system requests now display the requested document directly in MarkWisely instead of only showing its home screen

## 中文

TerminalWisely 0.1.4 将 EditorWisely 扩展为文件工作区，并修复本机 Markdown 文档无法直接在 MarkWisely 打开的问题。

### 主要更新

- **EditorWisely 文件树** — 在编辑器中浏览本机和 SSH 主机目录，无需离开工作区即可打开文件
- **多文档标签** — 同时保留多份打开的文档，并在切换时保留各自的编辑状态
- **打开文本文件** — 在本机 Files 或 SSH Files 中双击文本文件，或通过操作系统打开本机文本文件，都会在普通尺寸的 EditorWisely 窗口中打开；可通过标题栏按钮显示文件树，文件树会展开到当前文件所在目录
- **打开 Markdown 文档** — 操作系统打开请求现在会直接显示指定文档，不再只显示 MarkWisely 主界面
