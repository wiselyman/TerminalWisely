# TerminalWisely v0.0.1

Cross-platform **SSH terminal** with SFTP file workspace and **AI Linux Engineer** — describe Linux problems in natural language on connected hosts.

## Highlights

- Multi-tab SSH, bookmarks, drag-and-drop upload, `ls` click-to-enter, preview/edit, download, cross-server send
- AI Engineer on the live session (OpenAI-compatible, Ollama, Anthropic-compatible, Gemini)
- Policy-graded commands with approval UI; stop AI anytime
- Host metrics on the status bar; English and 中文 UI
- Installers: Windows, macOS (arm64 + x64), Linux (deb / rpm / AppImage, arm64 + x86_64)

## Install

Download the build for your OS from **Assets** below. AI dependencies install automatically on first use of AI Engineer.
