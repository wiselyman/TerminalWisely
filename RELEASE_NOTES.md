# TerminalWisely v0.0.1

## English

Public release of TerminalWisely: SSH terminal, host Desktop / Browser, SFTP workspace, Kubernetes workbench, and AI Linux / K8S Engineers in one desktop app.

### Highlights

- **SSH terminal** — multi-tab sessions, bookmarks, reconnect, English / 中文 UI
- **Host Desktop** — Files, Processes, and Browser as dock apps on the connected host; layout remembered per host tab
- **Host Browser** — browse remote HTTP (including `127.0.0.1`) through the live SSH session; multi-tab chrome with history and bookmarks
- **Host files** — Finder-style tree + contents (list/grid), back/up path bar, drag multi-select move with sudo retry, native PDF preview
- **Markdown** — Typora-like WYSIWYG editing (Vditor IR) in the preview panel
- **Appearance** — dark / light theme switch next to language in the title bar
- **Kubernetes** — sidebar Hosts ↔ K8s; kubeconfig or SSH kubectl; resource tree, YAML, logs, Pod shell; one-click kubectl/Helm into app data dir
- **AI Engineers** — Linux mode on the live SSH session; K8S mode on the selected cluster; long runs keep the SSH lease; personal / host / cluster memory and skills isolated by mode
- **Models** — OpenAI-compatible, Ollama, Anthropic-compatible gateways, Gemini
- **Safety** — policy-graded commands, approval cards, stop anytime
- **Insight** — host CPU, memory, disk I/O, and network on the status bar

Installers: Windows, macOS (arm64 + x64), Linux (deb / rpm / AppImage where available).

## 中文

TerminalWisely 公开发布：SSH 终端、主机 Desktop / Browser、SFTP 工作区、Kubernetes 工作台，以及 AI Linux / K8S Engineer，集成在同一桌面应用。

### 要点

- **SSH 终端** — 多标签、书签、断线重连、中英文界面
- **主机 Desktop** — 已连接主机上的 Files / Processes / Browser Dock 应用；按主机标签记忆布局
- **主机 Browser** — 经现有 SSH 访问远端 HTTP（含 `127.0.0.1`）；多标签、历史与书签
- **主机文件** — 左树右内容（列表/网格）、后退/上一级与路径栏跟随、多选拖拽移动（sudo 重试）、原生 PDF 预览
- **Markdown** — 预览面板内类 Typora 所见即所得编辑（Vditor IR）
- **外观** — 标题栏语言旁可切换深色 / 浅色主题
- **Kubernetes** — 侧栏 Hosts ↔ K8s；kubeconfig 或 SSH kubectl；资源树、YAML、日志、Pod Shell；可一键安装 kubectl/Helm 到应用数据目录
- **AI 工程师** — Hosts 为 Linux 模式；K8s 为 K8S 模式；长任务续租 SSH；个人 / 主机 / 集群记忆与 Skills 按模式隔离
- **模型** — OpenAI 兼容、Ollama、Anthropic 兼容网关、Gemini
- **安全** — 命令能力分级、批准卡片、随时停止
- **可观测** — 状态栏 CPU、内存、磁盘与网络

安装包：Windows；macOS（arm64 / x64）；Linux（deb / rpm / AppImage，视平台而定）。
