# TerminalWisely v0.1.4

## English

TerminalWisely 0.1.4 makes EditorWisely a file workspace and fixes direct opening of local Markdown documents in MarkWisely.

### Highlights

- **EditorWisely file tree** — browse local and SSH-host directories from the editor and open files without leaving the workspace
- **Multiple editor tabs** — keep several documents open and switch between them while retaining each document's editing state
- **Open text files** — double-click text files in Local Desktop Files or SSH Files, or send an operating-system file-open request, to open them in a normal EditorWisely window; toggle the file tree from the title bar, where it expands to the active file's directory
- **Open Markdown documents** — operating-system requests now display the requested document directly in MarkWisely instead of only showing its home screen

## 中文

TerminalWisely 0.1.4 将 EditorWisely 扩展为文件工作区，并修复本机 Markdown 文档无法直接在 MarkWisely 打开的问题。

### 主要更新

- **EditorWisely 文件树** — 在编辑器中浏览本机和 SSH 主机目录，无需离开工作区即可打开文件
- **多文档标签** — 同时保留多份打开的文档，并在切换时保留各自的编辑状态
- **打开文本文件** — 在本机 Files 或 SSH Files 中双击文本文件，或通过操作系统打开本机文本文件，都会在普通尺寸的 EditorWisely 窗口中打开；可通过标题栏按钮显示文件树，文件树会展开到当前文件所在目录
- **打开 Markdown 文档** — 操作系统打开请求现在会直接显示指定文档，不再只显示 MarkWisely 主界面

# TerminalWisely v0.1.3

## English

TerminalWisely 0.1.3 restores Home as a host directory, with Local pinned above saved SSH hosts grouped by the user's existing layout.

### Highlights

- **Home host directory** — open local Terminal and chat from Home, or select Local / an SSH host to open its Desktop workspace in a titlebar tab
- **Local Desktop tab** — open the local Desktop without creating an SSH session; Local and SSH workspaces retain separate state
- **Saved SSH hosts** — reuse the existing credential prompt and connection flow, then open Desktop in the new SSH session tab
- **Home chrome** — remove the sidebar collapse control and AI/Desktop shortcuts while the Home directory is active
- **MarkWisely workspace** — open local and SSH Markdown files in an integrated, full-window workspace with titlebar tabs, a Markdown file tree, and an outline for heading navigation
- **Window controls** — distinguish closing a document tab from closing the MarkWisely workspace; use the available window width for the document and formatting toolbar
- **Files navigation** — simplify the Markdown file navigation and search controls

## 中文

TerminalWisely 0.1.3 恢复 Home 主机目录，Local 固定在最上方，已保存 SSH 主机沿用现有分组布局。

### 主要更新

- **Home 主机目录** — 可从 Home 进入本机 Terminal 和聊天，也可选择 Local 或 SSH 主机，在标题栏标签打开对应 Desktop
- **本机 Desktop 标签** — 打开本机 Desktop 时不创建 SSH 会话；本机与 SSH 工作区状态保持隔离
- **已保存 SSH 主机** — 沿用现有凭据提示和连接流程，在新 SSH 会话标签打开 Desktop
- **Home 界面** — Home 目录显示时不提供侧栏收起控件或 AI/Desktop 快捷按钮
- **MarkWisely 工作区** — 本机与 SSH Markdown 文件均可在集成的全窗口工作区打开，提供标题栏文档标签、Markdown 文件树和标题大纲导航
- **窗口操作** — 文档标签关闭与 MarkWisely 工作区关闭各自独立；正文和格式工具栏使用可用窗口宽度
- **Files 导航** — 简化 Markdown 文件导航和搜索控件
