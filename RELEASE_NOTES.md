# TerminalWisely v0.0.3

## English

### Kubernetes workbench + AI K8S Engineer

- Sidebar activity bar: **Hosts** ↔ **K8s**
- Local kubeconfig contexts and SSH kubectl jump-host bindings
- Lens-style resource tree (Pods, Deployments, Services, Nodes, Events, …), YAML editor, Apply / Delete / Scale with confirmation
- Pod logs (polling) and Pod shell (SSH session inject; local copies the kubectl exec command)
- **AI K8S Engineer** in the same panel as Linux Engineer — mode follows the sidebar; chat history isolated by cluster vs host
- Sidecar `k8s_*` tools with PolicyEngine approval for mutations

### Also in this release

- Welcome page and README cover Linux + Kubernetes ops

Installers: Windows, macOS (arm64 + x64), Linux (deb / rpm / AppImage where available).
